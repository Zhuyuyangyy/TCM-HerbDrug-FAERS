# 中西药相互作用风险信号挖掘系统 — 技术交底书

## 一、项目名称与定位

**项目名称**: 基于FAERS/VigiBase与中药-成分-处方知识图谱的中西药相互作用风险信号挖掘系统

**定位**: 面向药物警戒的智能信号检测与机制解释平台，为临床中西药安全联用提供数据驱动的风险评估。

## 二、核心创新点

### 创新点1: 多指标联合信号检测
同时采用ROR、PRR、IC三种不成比例分析指标，互相验证，降低假阳性。

### 创新点2: 机制解释图谱
构建中药-成分-靶点-CYP/转运体-不良事件的完整机制链，不仅发现信号，还解释"为什么"。

### 创新点3: 三级风险排序
从纯统计信号到有数据库支持再到有机制解释，三级递进，符合循证医学逻辑。

### 3.2 关键算法

**ROR (Reporting Odds Ratio)**:
ROR = (a×d)/(b×c), 95%CI = exp(ln(ROR) ± 1.96×SE)

**PRR (Proportional Reporting Ratio)**:
PRR = [a/(a+b)] / [c/(c+d)]

**IC (Information Component)**:
IC = log2(a/n_exp), n_exp = (n1·× n·1)/n
